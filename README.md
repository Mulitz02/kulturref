# Kulturref HBC

Planungs-App für das Kulturreferat der Verfassten Studierendenschaft der Hochschule Biberach.

**App öffnen:** https://mulitz02.github.io/kulturref

- Fällige Aufgaben über alle Partys hinweg, mit Zuständigkeit und Live-Abgleich
- Checklisten je Party-Art mit automatisch berechneten Fristen
- Security-Planung mit fertigem Text zum Weiterleiten
- Packlisten, Kontakte, Notizen für die Übergabe

Zugang nur für freigeschaltete Mitglieder (Login mit Google oder E-Mail-Link).
Die Inhalte liegen in einer geschützten Firebase-Datenbank, nicht in diesem Repository.

Auf dem iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
